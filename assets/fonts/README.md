# Self-hosted fonts

Daily Applied Wisdom serves these webfonts from the same GitHub Pages origin so
rendering does not require a request to Google Fonts:

- DM Mono 400 and 500
- DM Serif Display 400 normal and italic
- Manrope variable font, weights 400 through 700

The files are the Latin and Latin-extended WOFF2 assets distributed by Google
Fonts. Each family is licensed under the SIL Open Font License 1.1; the
corresponding unmodified license and copyright notice is stored beside the font
files.
